# MeshNotes Relay Server

## Run

```bash
fvm dart pub get
fvm dart run bin/server.dart --gen-key --dir ./server_data
fvm dart run bin/server.dart --port 17974 --dir ./server_data
# Enable debug logs when needed:
fvm dart run bin/server.dart --port 17974 --dir ./server_data --debug
```

## Configuration

`server_data/server_config.yaml` is generated by `--gen-key` and then owned by the operator.

```yaml
private_key: "..."
public_key: "..."
device_id: "server_..."
user_name: "relay_server"
max_query_versions_per_apply: 2
```

`max_query_versions_per_apply` limits how many missing versions the server requests per query after a client `apply`. Default is `2`; the server requests the next batch after it stores the previous `provide` response, so smaller batches avoid making the app assemble/encrypt too much data at once.
